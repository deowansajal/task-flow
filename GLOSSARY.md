# TaskFlow

TaskFlow manages one person's personal task list.

## Language

**Task**:
One actionable item with a required title, an optional plain-text description, one status, and one priority.
_Avoid_: Ticket, issue, to-do

**Status**:
A task's progress state: TODO (not started), IN_PROGRESS (underway), or DONE (completed).

**Priority**:
A task's relative importance: LOW, MEDIUM, or HIGH. Priority is independent of status.
